# Pentaprima Premium Cat Food - Modern Website

Website modern dengan desain premium Jotun-style untuk brand makanan kucing Pentaprima.

## 🎨 Fitur Desain

- **Modern Premium Design**: Terinspirasi dari brand premium seperti Jotun dengan color scheme emas dan background gelap
- **Smooth Animations**: 
  - Hero section dengan slide-in animations
  - Floating badges dengan animasi smooth
  - Product cards dengan hover effects yang elegan
  - Scroll-triggered fade-in animations
  - Navbar dengan blur backdrop effect

- **Responsive Layout**: Fully responsive untuk desktop, tablet, dan mobile
- **Performance Optimized**: Menggunakan CSS animations untuk performa optimal
- **Accessibility**: Semantic HTML dan proper contrast ratios

## 🎯 Sections

1. **Hero Section**
   - Compelling headline dengan gradient text
   - Feature highlights
   - CTA buttons
   - Floating badges dengan statistik

2. **Products Section**
   - Product grid dengan 3 varian (Kitten, Adult, Senior)
   - Product cards dengan hover animations
   - Price dan action buttons
   - Product badges (Best Seller, Premium)

3. **Benefits Section**
   - Benefits list dengan icons
   - Image showcase dengan zoom effect on hover
   - Icon-based feature highlights

4. **Testimonials Section**
   - Star ratings
   - Customer testimonials
   - Author avatars
   - Smooth animations on scroll

5. **CTA Section**
   - Call-to-action dengan gradient background
   - Prominent button for conversions

6. **Footer**
   - Multi-column layout
   - Links to key pages
   - Contact information
   - Copyright and policies

## 🎬 Animation Highlights

- **Hero animations**: Slide in from left/right dengan timing berbeda
- **Float animations**: Badges yang floating up-down
- **Scroll animations**: Fade-in dan slide-up saat scrolling ke view
- **Hover effects**: Scale, color, dan shadow transitions
- **Button animations**: Shimmer effect on hover

## 🚀 Cara Menggunakan

1. Clone repository ini
2. Buka `index.html` di browser
3. Customize content, warna, dan images sesuai kebutuhan
4. Deploy ke hosting pilihan Anda

## 📝 Kustomisasi

### Mengubah Warna
Edit CSS variables di `:root` section dalam `<style>`

### Mengganti Gambar
Replace URL gambar Unsplash dengan gambar produk Anda sendiri

### Menambah Produk
Copy section `.product-card` dan paste di dalam `.products-grid`

### Mengubah Teks
Edit content HTML sesuai dengan data Pentaprima asli
